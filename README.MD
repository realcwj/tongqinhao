# 通琴号 · 跨境通勤助手

横琴 ⇄ 澳门跨境通勤班次查询网页应用。根据你的位置或手动选择，快速找到最近的上车站点，掌握后续班次与车辆状态。

🔗 **在线使用**：<https://realcwj.github.io/tongqinhao/>

📦 **项目仓库**：<https://github.com/realcwj/tongqinhao>

---

## ✨ 功能特性

- **自动定位**：打开页面自动申请定位，判断你当前在横琴还是澳门，并推荐 1 公里内最近的 5 个上车站点。
- **快速选择**：一键直达常用线路，例如「琴澳大学城 → 澳大」「澳大 → 琴澳大学城」，自动设置区域、上车站点与下车站点并跳转班次结果。
- **双向跨境规则**：横琴上车只能前往澳门下车，澳门上车只能前往横琴下车，站点推荐按线路方向自动过滤。
- **多选站点**：可同时选择多个上车站点 / 下车站点，合并查询所有相关班次并去重。
- **站点时间轴**：每个班次可展开完整站点时刻，标记上车点与可下车点。
- **车辆状态**：未发车、在某站、两站之间、已到终点等实时状态展示。
- **全部线路页**：浏览全部 72 条跨境线路，支持关键词搜索与方向筛选，展开查看完整站点时刻。

## 🖥 页面说明

| 页面 | 说明 |
| --- | --- |
| `index.html` | 通勤助手主页：定位 → 快速选择 → 我当前在 → 附近站点 → 选择上/下车站 → 后续班次 |
| `routes.html` | 全部跨境线路目录：搜索、筛选、展开线路站点时刻 |

## 📦 项目结构

```
├── index.html          # 通勤助手主页
├── routes.html         # 全部跨境线路页
├── app-v2.js           # 主页逻辑（定位、选择、班次查询）
├── routes.js           # 线路页逻辑
├── styles.css          # 全局样式
├── processed.json      # 前端唯一业务数据源（72 条线路、705 条站点记录）
├── get_all_route.py    # 数据抓取与整理脚本（*暂不提供）
└── json/               # 抓取原始 JSON（*暂不提供）
```

## 🚀 本地运行

项目为纯静态页面，任意静态服务器即可运行：

```bash
# Python
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000/
```
